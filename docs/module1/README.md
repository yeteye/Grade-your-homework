# 模块一测试协作

本阶段以 `2da8824d3638f4a475e4fe80dbe11d5fdaf9b0d4` 为被测基线，只记录此后开展的课程测试活动。成员 A 负责评分和输入校验，成员 B 负责批量批改、模板、记录、统计和导出。报告不涉及基线形成之前的开发或维护过程。

## 成员 A 范围

- `homework/validation.py`：文本、数值、评分选项和评分要点校验。
- `homework/scoring.py`：规范化、字符多重集合 Dice、加权要点、得分和达标判断。
- `homework/ai_grader.py`：外部评分响应的确定性解析和失败回退契约。
- `POST /compare_texts`：上述逻辑的接口集成以及失败时不保存记录。
- 模型适配边界采用替身验证；不评价真实 OCR、Transformer 或云端模型的准确率。

## 本机运行

在项目根目录执行 `setup.bat` 安装基础依赖，再运行 `run-module1.bat --suite all --label <本轮唯一名称>`。其中 `all` 包含现有开发检查与课程用例，`course` 只运行课程用例，`checks` 只运行开发检查。结果写入 `reports/module1/<名称>.json` 和 `.txt`。生成的唯一名称不可覆盖，用于保留各轮证据。运行 `run-module1.bat --suite course --source-ref 2da8824 --label <唯一名称>` 可使用 Git archive 对冻结基线重放当前课程用例。该命令需要本地可用的 Git，且不依赖真实 OCR、模型或云端服务。
