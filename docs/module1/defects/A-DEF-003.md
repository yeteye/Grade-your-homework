# A-DEF-003 非法模型概率经要点混合后生成有效成绩

- 被测基线：`2da8824`
- 发现人：曹浩（M202677234）
- 关联用例：A-021
- 严重程度：高；优先级：高
- 状态：已修复并回归通过
- 证据：`reports/module1/a-defects-baseline.json`，`test_a021_invalid_model_probability_cannot_be_hidden_by_rubric`

## 复现

对本地 Transformer 适配器使用确定性替身，返回不可能的概率 `2.0`。向 `POST /compare_texts` 提交作答 `A`、参考答案 `AB`，并给出未命中的要点 `Z`。

预期：模型概率超出 0～1，应返回 503，提示评分引擎无效，且不保存记录。

实际：基础概率 `2.0` 与要点覆盖率 `0` 按 `40%/60%` 混合成 `0.8`，接口返回 200 和 80 分，并保存记录。代码只验证混合后的最终值，未验证各个输入分数。

## 影响与修复验证

评分引擎异常可能被权重计算掩盖，生成看似正常的成绩。修复提交 `103d09e` 在要点和 AI 权重计算前验证基础分范围及有限性，并把浮点溢出转换成评分不可用。`reports/module1/a-final-full.json` 中 A-021 的 `-0.1`、`2.0`、NaN、Infinity 四种异常替身均被拒绝，未保存记录；正常评分用例通过。
