## 1 被测对象概述

被测对象为“阅知 Homework Studio”的评分与输入校验模块。`server.py` 的 `/compare_texts` 接口接收作答、参考答案及评分设置；`homework/validation.py` 校验输入、分数范围和要点；`homework/scoring.py` 实现 NFKC 规范化、字符多重集合 Dice、要点加权、达标判断；`homework/ai_grader.py` 解析可选云端评分并在失败时回退。本阶段以冻结提交 `2da8824` 为起点，先复现缺陷，再对本阶段修复提交执行回归。

## 2 测试计划与策略

### 2.1 测试范围

覆盖单份文本批改的参数边界、相似度算法、要点配置、权重计算、分数有效性和错误响应；检查失败请求是否保存记录。真实 OCR 识别率、Transformer 教学评分准确率及云端 AI 评分质量不在成员 A 的判断范围。对外部依赖采用固定替身，只验证应用如何处理其返回值和故障。

### 2.2 测试策略

成员 A 22 条正式用例分别使用等价类 6 条、边界值 9 条、场景法 7 条。等价类用于空白、非法类型、规范化等价文本；边界值覆盖 5000 字、满分 1～1000、百分率 0～100、要点数量和权重；场景法连接评分输入、结果、记录保存与失败回退。每个正式编号可含多组参数变体，但总数只计编号一次。输入预期依据本版本 README 的功能边界及本阶段确认的接口契约，详情见 `tests/module1/cases_a.json` 和交付用例 Excel。

### 2.3 测试环境

Windows x64；Python 3.12.14、Flask 3.1.3、Pillow 12.3.0、Werkzeug 3.1.8。每个接口测试建立独立临时 SQLite 数据库，云端网络调用被测试替身拦截。基础依赖由 `setup.bat` 安装。`run-module1.bat --suite all --label <唯一名称>` 一键运行课程用例和原有开发检查，并保存 JSON 与文本日志。完整解释器、平台、依赖、源文件 SHA-256 和用例状态均写入 `reports/module1/a-final-full.json`。

### 5.2 缺陷摘要

本阶段成员 A 发现并完成回归验证的有效缺陷共 4 个：A-DEF-001 超大评分数值触发 500；A-DEF-002 规范化等价要点重复计权；A-DEF-003 非法模型概率被权重混合为有效成绩；A-DEF-004 超大云端分数未触发本地回退。具体输入、现象、修复提交及证据见各缺陷记录。A-DEF-003 因可能保存错误成绩标为高严重程度，其余标为中。

### 5.3 典型缺陷根因分析

A-DEF-002 的校验函数仅使用 `casefold()`，匹配函数则使用 NFKC、大小写折叠和非文字数字字符过滤，因此看似不同的两个关键词在评分时等价。修复 `ec22c91` 将规范化提到共享函数，并用它做去重；A-020 修复前失败，修复后通过。

A-DEF-003 在要点加权后才检查最终分数范围，非法模型输出 `2.0` 经 40% 权重与零覆盖率混合后变成 `0.8`，接口保存了 80 分。修复 `103d09e` 在混合前验证基础分的范围和有限性；A-021 的 -0.1、2.0、NaN、Infinity 变体均通过回归，未保存错误记录。

A-DEF-001 与 A-DEF-004 都涉及超大整数转浮点时的 `OverflowError`，但位于两个不同入口。修复 `358a085` 和 `7ca7fc1` 分别恢复了参数错误提示和云端失败回退契约。相关 A-019、A-022 已通过。
