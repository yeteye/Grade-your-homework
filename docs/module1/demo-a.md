## 现场运行命令（PowerShell）

在项目根目录、已执行 `setup.bat` 的环境中：

```powershell
$label = 'demo-a-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
.\run-module1.bat --suite all --label $label
```

输出位于 `reports/module1/$label.json` 和 `$label.txt`。原始封存证据为 `reports/module1/a-defects-baseline.json`（A 用例 18/22 通过）与 `reports/module1/a-final-full.json`（A 用例 22/22、既有检查 21/21 通过）。录制前确认现场复跑仍通过；如环境差异导致失败，应保留真实输出并排查，不能用旧日志冒充现场运行。
